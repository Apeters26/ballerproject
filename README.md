# ballerproject

## Autonomous drone simulator

The first release is a virtual flight challenge for two collaborators developing Python controllers on ordinary laptops. One quadcopter must take off, pass five gates in order and land. A recorded flight lets either developer see exactly where the controller succeeded or failed.

The project is in the specification stage. Read the documents in this order.

1. [Product specification](docs/product-spec.md) — what an operator can do, how a flight earns credit and what evidence the MVP must produce.
2. [Technical specification](docs/technical-spec.md) — course geometry, flight control, judging, run recordings and implementation tests.
3. [Roadmap](docs/roadmap.md) — how two contributors can deliver the first flight, then compare controllers across harder courses and conditions.
